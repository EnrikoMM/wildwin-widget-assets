# WildWin widget images

Images for the WildWin Lucky Wheel CMS widget, served through jsDelivr:

    https://cdn.jsdelivr.net/gh/EnrikoMM/wildwin-widget-assets@v1/<file>

- `wheel-disk.webp`, `wheel-rim.webp`, `wheel-pointer.webp`, `wheel-play.webp`: the wheel (phone and web card)
- `wheel-web-*`: the web card (sky, plate, jackpot, coins, clover, Wynn, chests, key icons) and its stylesheet `wheel-web.css`

Tags are immutable releases; publish changes as a new tag (v2, v3, ...) and update the widget's ASSET_BASE.
